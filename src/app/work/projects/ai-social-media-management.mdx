## Context

During my Software Engineering internship at Sarıtay Bilişim in Antalya (June–August 2026), I developed a full-stack, AI-powered social media management web application.

## Full-stack development

I worked with ASP.NET Core for backend development and Angular for the frontend. My contributions included backend application logic and integrating frontend components with RESTful APIs to support social media management workflows.

## Contextual AI integration

I integrated AI-powered content generation using LangChain and Model Context Protocol (MCP). An Obsidian-based LLMWiki supplied brand-specific knowledge and contextual information for the content generation features.

## Delivery workflows

I worked with GitLab CI/CD pipelines to automate application build, testing, and deployment workflows across Development, Staging, and Production environments.

## Technologies

C#, ASP.NET Core, Angular, TypeScript, RESTful APIs, LangChain, MCP, Obsidian, LLMWiki, Git, and GitLab CI/CD.

This overview describes my development contributions during the internship. No public repository or demo is linked for this internship application.
