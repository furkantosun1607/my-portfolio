## Context

During my Information Technology internship at Sütaş in Bursa (August–September 2026), I gained hands-on experience with enterprise infrastructure, network operations, and technical documentation. SutasGPT was a prototype designed to improve access to internal IT knowledge.

## My contribution

I designed an AI-powered internal knowledge management prototype using LLMWiki, retrieval-augmented generation (RAG) concepts, and Streamlit. The aim was to make infrastructure documentation and technical information easier to access through an AI-assisted interface.

## Related infrastructure work

- Supported network connectivity and infrastructure troubleshooting.
- Contributed to Cisco network configuration, VLAN segmentation, and wireless network optimization.
- Participated in network access control operations involving IEEE 802.1X and MAC Authentication Bypass (MAB).
- Developed Excel VBA tools for hardware maintenance tracking, infrastructure inventory management, and documentation workflows.

## Technologies

LLMWiki, RAG concepts, Streamlit, and LLM integration. Related internship work involved Cisco networking, NAC, and Excel VBA.

## Scope

SutasGPT was an internal knowledge management prototype. This overview describes my internship contribution; it does not include internal documentation or a public demo.
