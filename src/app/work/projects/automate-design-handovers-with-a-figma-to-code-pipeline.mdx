## Overview

Development of an end-to-end autonomous media platform designed to combat information overload. The system leverages Generative AI to ingest global news feeds, synthesize them into concise, unbiased summaries, and distribute them across social media channels and a dedicated mobile application. The project aims to transform how users consume daily information by offering personalized, audio-first news experiences (podcasts) generated in real-time.

## Key Features

- **Automated Content Pipeline**: Engineered a Python-based bot that continuously monitors diverse RSS feeds (Economy, Sports, Tech), filters for high-impact stories, and uses Google Gemini to generate engaging, platform-specific content (e.g., Twitter threads, blog posts).

- **AI-Driven Personalization & Synthesis**: Implemented advanced prompt engineering to create distinct "Personas" (e.g., "The Analyst," "The Friend"). The system doesn't just summarize; it synthesizes conflicting reports and provides context, adapting the tone to the specific news category.

- **Smart Memory Management**: Built a state-management system to track published content, preventing duplication and ensuring a fresh stream of unique news updates 24/7.

- **Audio Briefing Generation (TTS)**: Designed the architecture for an "On-the-Go" news app that converts text summaries into natural-sounding audio podcasts, allowing users to listen to their personalized daily briefings.

- **Multi-Channel Network**: Structured the system to manage multiple accounts simultaneously (TSN Sports, TSN Tech), tailoring the content strategy for different audience segments automatically.

## Technologies Used

- **Core Logic**: Python (Automation scripting, Cron jobs).
- **Artificial Intelligence**: Google Gemini API (LLM for content generation & sentiment analysis).
- **Data Ingestion**: Feedparser, REST APIs.
- **Distribution**: X (Twitter) API integration.
- **Future Stack**: Text-to-Speech (TTS) models, Flutter (Mobile App), Azure Functions (Serverless architecture).

## Challenges and Learnings

A primary challenge was ensuring the reliability and factual accuracy of AI-generated content (mitigating hallucinations). The solution involved strict prompt engineering and implementing a "fact-check" layer where the AI cross-references data before publication. Additionally, managing API rate limits on social platforms required developing an intelligent scheduling algorithm that balances content freshness with platform constraints.

## Outcome

The project successfully evolved from a manual concept into a fully automated media engine capable of running without human intervention. It demonstrates the practical application of LLMs in media workflows, significantly reducing the time required to curate and publish high-quality news, while laying the foundation for a scalable, subscription-based mobile news platform.
